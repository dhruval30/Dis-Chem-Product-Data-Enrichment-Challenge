# Rules

> Source: Zindi competition Rules page, supplied 2026-11-14. This is a working summary for modelling and submission decisions, not legal advice. The full rules on the competition page control.

## Languages and tools

- Python only.
- Publicly available open-source packages only. No paid services or free trials that require a credit card.
- Pretrained models are allowed only if they are openly available to everyone.
- Automated machine learning tools such as AutoML are not permitted.
- Custom packages in a submitted notebook or solution are not accepted.

## Data

- Use only the datasets provided for this challenge. External data is not permitted, even public data.
- The challenge data is released under CC-BY-SA 4.0 and may be used and shared for commercial, non-commercial, research and education purposes under that licence.
- Do not use competitor or retailer pages, reviews, forums, search snippets, generic web pages or AI-generated answers as evidence. The product enrichment guardrails explicitly prohibit browsing or general knowledge to fill gaps.
- Notify Zindi of any unauthorised transmission or access to the data.

## Submissions

- Maximum 2 submissions per day.
- Maximum 20 submissions overall.
- Before close, select 2 submissions for private leaderboard judging. If no selection is made, the 2 best public submissions are used.
- A submission that fails processing does not count against the daily limit.
- Ties are broken by submission time; the earlier submission wins.

## Teams

- Maximum team size is 4.
- One account per person; no collaboration or membership across multiple teams.
- Team formation is allowed only while the team's combined submission count is within the limit.
- No new members may be added in the final 5 days.
- Code must not be shared privately outside a team; shared code must be public to all participants.

## Code review and reproducibility

- The top 10 on the private leaderboard are emailed for code at the end of Phase 1 and have 48 hours to respond.
- The code must run and reproduce the leaderboard score, or Zindi may adjust the rank to what the code produces.
- Always set the seed. Rerunning the model should produce the same result.
- Prepare documentation and follow Zindi's code-review guidance.
- Winners assign worldwide copyright in the winning solution code to Zindi and must provide identification, proof of residence and bank confirmation.

## Conduct

- Multiple accounts, account sharing and cheating lead to disqualification, prize bans of six months and removal of 2,000 points.
- Zindi may request code at any time during the challenge, with 24 hours to respond.
- Zindi reserves the right to disqualify submissions on usability or value grounds, including data leaks.

## Phase 1 constraints

- End-to-end inference: 3 hours maximum.
- All-in inference cost: US$20 maximum.
- One GPU, at most 24 GB VRAM.
- At most one retry per failed call, included in the caps.
