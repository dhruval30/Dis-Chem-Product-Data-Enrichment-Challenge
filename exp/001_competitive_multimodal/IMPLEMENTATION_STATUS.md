## Deliberate limits

Clearly read image-only facts can be eligible after visible identity checks. High-risk image facts require stricter confidence and OCR agreement or an agreeing separate visual read. Self-reported confidence and repeated reads are not calibrated or independent guarantees. Catalogue family transfer is restricted to approved shared fields with consensus and target corroboration, except application area for an identically named product differing only in size. Review that assumption by category. Related-product descriptions remain non-transferable context.

The mirrored challenge pages state three-hour and US$20 caps, while the user reports these are not established on the current official Phase 1 page. Their authority remains unconfirmed. Time and cost limits now default to null; cumulative monitoring and an optional local memory ceiling remain. No current official page was fetched during this revision.

Pseudo targets are automatically extracted silver labels and masking is coarser than the test distribution. Prose verification and OCR table association are conservative lexical checks, not a hidden LLM judge or proof that a cited statement is true. Model-stage failures preserve deterministic evidence and source-description fallbacks; degraded records are explicitly counted.

The runtime monitor cannot preempt a native library call. Reserve headroom for release validation and submission serialisation, which are separate CLI invocations. Cost reporting depends on the configured all-in local hourly rate. A resolved transitive environment lock must be created after installation; the direct requirements and core MLX versions are pinned now.
